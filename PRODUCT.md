# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Travelers who want to find and book suitable accommodation. Their primary job is to discover an appropriate place to stay quickly.

## Product Purpose

4LIFE helps travelers find and book accommodation. Success means travelers can identify a suitable place and complete the existing booking flow with clear information.

## Positioning

The confirmed product priority is helping travelers find suitable accommodation quickly. A distinctive mechanism beyond this priority is not yet established.

## Operating Context

The current web application supports accommodation discovery, accommodation details, booking, account management, favorites, reviews, and accommodation-post management. The product is implemented as a React and TypeScript web application.

## Capabilities and Constraints

- Existing routes and booking/payment behavior are product constraints for the redesign.
- Preserve current functions, API behavior, access control, and route structure unless the user approves a change.
- The current stack is React 18, TypeScript, Vite, React Router 6, Redux Toolkit, Material UI 5, and SCSS Modules.
- Product policies and detailed booking rules must be confirmed from the implementation or product owner; do not invent them.

## Brand Commitments

- Preserve the 4LIFE name and logo.
- The user approved a strong visual redesign. The current color palette and visual styling are not binding commitments.
- The user approved the “Atlas khu phố” visual direction and the desktop split layout with accommodation results beside a map for the Rooms surface.

## Evidence on Hand

- Current implementation and routes in `src/App.tsx` and `src/pages/`.
- Existing logo asset: `src/assets/images/logo.png`.
- Accommodation and introductory image assets exist under `src/assets/images/`; confirm usage rights and content before reuse.
- No user research, validated performance metrics, testimonials, or confirmed differentiator beyond fast accommodation discovery were provided. Do not fabricate them.

## Product Principles

- Help travelers find suitable accommodation quickly.
- Keep accommodation and booking information clear enough to support a decision.
- Preserve established product behavior during visual redesign.
- Do not present unverified claims, policies, or performance figures as facts.
